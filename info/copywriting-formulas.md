# Copywriting Formulas — Hormozi Method

Battle-tested formulas for headlines, CTAs, and social proof based on Alex Hormozi's $100M frameworks.

**The 80% Rule:** Once you write the headline, you've spent 80 cents of your advertising dollar. Headlines ARE the ad.

---

## Section 1: Headline Formulas

### Formula 1: Outcome + Timeline + Barrier Removal (Primary)

**Structure:**
```
[Achieve DREAM OUTCOME] in [SPECIFIC TIME] without [BIGGEST BARRIER]
```

**Examples:**

| Market | Headline |
|--------|----------|
| Marketing | Get 50+ Qualified Leads Per Month in 90 Days — Without Spending $1 on Ads |
| Fitness | Lose 20 Pounds in 12 Weeks — Without Giving Up Your Favorite Foods |
| Freelance | Land 3 High-Paying Clients This Month — Without Cold Calling or Networking Events |
| Education | Get Your First 100 Students in 60 Days — Without Complex Funnels or Tech Skills |

**Hebrew Examples:**

```
השג 50+ לידים איכותיים בחודש תוך 90 יום — בלי להוציא שקל אחד על פרסום
הכפל את המכירות שלך ב-90 יום — בלי לבזבז כסף על פרסום שלא עובד
קבל 3 לקוחות משלמים החודש — בלי שיחות קרות או אירועי נטוורקינג
```

**Why it works:**
- **Outcome:** What they want (dream)
- **Timeline:** How fast (reduces time delay)
- **Barrier:** What's been stopping them (removes effort/fear)

## Section 2: Subheadline Formulas

**Purpose:** Support headline, add clarity, remove next-biggest barrier

### Formula 1: Method + Proof + Qualifier

**Structure:**
```
[HOW IT WORKS] that's helped [NUMBER] [TYPE OF PEOPLE] [ACHIEVE RESULT] — even if [BARRIER]
```

**Examples:**

```
A simple 3-step system that's helped 500+ freelancers land clients — even if you have zero followers
The proven framework used by 1,200+ businesses to generate leads — without complex funnels or tech skills
```

### Formula 2: Value Stack

**Structure:**
```
Get [BENEFIT 1], [BENEFIT 2], and [BENEFIT 3] — without [SACRIFICE]
```

**Examples:**

```
Get more leads, higher conversion, and better clients — without spending hours creating content
Build a profitable business, work from anywhere, and have time for family — without burning out
```

## Section 3: CTA Formulas

### Formula 1: What + Next + Why (Primary)

**Structure:**
```
[ACTION VERB] → [Immediate Result] → [Why It Matters]
```

**Examples:**

| Industry | CTA |
|----------|-----|
| Course | Get Your Free Strategy Call → See Exactly Where You're Losing Sales → Start Fixing It This Week |
| Service | Claim Your Free Audit → Discover the #1 Thing Blocking Your Growth → Fix It in 30 Days |
| SaaS | Start Your Free Trial → See Results in 24 Hours → No Credit Card Required |

**Hebrew:**

```
קבל שיחת אסטרטגיה חינם → גלה בדיוק איפה אתה מפסיד מכירות → תתחיל לתקן השבוע

תבדוק חינם → גלה מה חוסם את הצמיחה שלך → תפתור תוך 30 יום
```

**Why it works:** Removes all 3 conversion blockers (what to do, what happens, why now)

---

### Formula 2: Command + Outcome

**Structure:**
```
[STRONG VERB] [OUTCOME] [TIMEFRAME]
```

**Examples:**

```
Get Your First 3 Clients This Month
Double Your Leads in 60 Days
Start Getting Paid What You're Worth
```

**Examples:**


## Section 4: Social Proof Formulas

### Formula 1: Before + After + Timeline (Primary)

**Structure:**
```
"[BEFORE STATE] → [AFTER STATE] in [TIME]. [SPECIFIC DETAIL]."
— [Full Name], [Credibility Marker]
```

**Examples:**

```
"Went from 2 clients/month to 12 in 6 weeks. Revenue up $18k. Stopped all paid ads."
— David Chen, Freelance Web Designer

"Was spending $3k/month on Facebook ads getting 5 leads. Now getting 40 leads/month organically, zero ad spend."
— Sarah Martinez, Business Coach

"First month: 0 students. Month 3: 87 paying students at $197 each. Finally quit my 9-5."
— Mike Johnson, Online Course Creator
```

**Hebrew:**

```
"עברתי מ-2 לקוחות בחודש ל-12 תוך 6 שבועות. הכנסה עלתה ב-70,000₪."
— דוד כהן, מעצב גרפי עצמאי

"הייתי מוציא 10,000₪ בחודש על פרסום ומקבל 3 לידים. עכשיו מקבל 25 לידים בחודש בלי לשלם על פרסום."
— שרה לוי, יועצת שיווק
```

**Required Elements:**
- ✓ Before state (with number)
- ✓ After state (with number)
- ✓ Timeline
- ✓ Full name + title/industry
- ✓ Optional: Surprising detail

## Section 5: Feature → Benefit Translation

**Rule:** Never list a feature without translating to outcome.

### Formula: Feature + So You Can + Outcome

**Structure:**
```
[FEATURE] → so you can → [IMMEDIATE BENEFIT] → which means → [ULTIMATE OUTCOME]
```

**Examples:**

| Feature | Translation |
|---------|-------------|
| "Weekly coaching calls" | "Weekly 1-on-1 coaching calls → so you can get unstuck immediately → which means you never waste weeks going in the wrong direction" |
| "50 templates" | "50 done-for-you templates → so you can post daily without creative burnout → which means consistent visibility bringing steady leads" |
| "Lifetime access" | "Lifetime access with free updates → so you stay current as platforms change → which means your system keeps working year after year" |

## Section 6: Urgency & Scarcity (With "Reason Why")

**Hormozi Rule:** ALWAYS provide a believable reason for urgency/scarcity. Never fake it.

### Real Scarcity Examples:

**Cohort-Based:**
```
Next cohort starts March 25. Only 20 spots (limited by 1-on-1 coaching capacity).
Enrollment closes March 22.
```

**Seasonal:**
```
Peak lead generation season is April-June. Start now to capture the wave.
Miss this window = wait 6 months for next seasonal surge.
```

**Capacity:**
```
I personally review every strategy call. Can only do 10/week.
Next opening: 2 weeks from today.
```

**Promotional:**
```
Celebrating 100th student. First 10 to enroll get $200 off.
After that, price returns to $997.
```

### Fake Urgency to AVOID:

❌ "Limited time offer!" (no reason given)
❌ "Only 3 spots left!" (resets every week)
❌ "Price goes up tomorrow!" (never actually goes up)
❌ Countdown timers that reset when you refresh

## Section 7: 3rd Grade Reading Level

**Hormozi Rule:** If a 3rd grader can't understand it, simplify.

### Simplification Table:

| Jargon | Simple |
|--------|--------|
| "Leverage our proprietary methodology" | "Use our simple 3-step system" |
| "Optimize your conversion funnel" | "Turn more visitors into customers" |
| "Implement a robust lead generation strategy" | "Get more people interested in your business" |
| "Utilize cutting-edge marketing automation" | "Send emails automatically so you save time" |

### Test: Read It Out Loud

If you stumble, it's too complex. Rewrite.

## Section 8: The "Reason Why" Formula

**Use when:** Adding discount, bonus, urgency, or any special condition

**Structure:**
```
[OFFER/CONDITION] because [BELIEVABLE REASON]
```

**Examples:**

**Discount:**
```
❌ "50% off for a limited time!"
✅ "50% off to celebrate our 100th student milestone"
```

**Bonus:**
```
❌ "Get this free bonus!"
✅ "I'm including my $500 Quick-Start Kit free because I want you to see results in week 1, not week 4"
```

**Urgency:**
```
❌ "Offer ends soon!"
✅ "Enrollment closes Friday because next cohort starts Monday and we need 48 hours to onboard everyone"
```

## Quick Copy Checklist

Before finalizing copy, verify:

**Headlines**
- [ ] States dream outcome (not method)
- [ ] Includes specific timeline
- [ ] Removes at least one barrier
- [ ] Under 20 words (readable in 3 seconds)

**CTAs**
- [ ] Uses What + Next + Why format
- [ ] Action verb (not "learn more")
- [ ] Appears 3+ times on page
- [ ] No friction (easy to click, minimal form fields)

**Social Proof**
- [ ] Before/after numbers
- [ ] Specific timeline
- [ ] Full name + title
- [ ] At least 3 testimonials

**Overall**
- [ ] 3rd grade reading level
- [ ] No jargon without explanation
- [ ] Features translated to benefits
- [ ] "Reason why" for all urgency/scarcity
- [ ] Every section passes "So what?" test
