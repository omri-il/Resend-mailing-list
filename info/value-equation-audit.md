# Value Equation Audit — Scoring Rubric

Comprehensive scoring system for website conversion optimization based on Hormozi's Value Equation framework.

```
Value = (Dream Outcome × Perceived Likelihood)
        ─────────────────────────────────────
              (Time Delay × Effort)
```

**Total Score:** 100 points
**Passing Threshold:** 70/100
**Excellent:** 85+/100

---

## Component 1: Dream Outcome (25 points)

**What it measures:** Does the site clearly communicate the END RESULT the user wants?

### Scoring Breakdown

**Hero Headline (15 points)**

| Score | Criteria |
|-------|----------|
| 15 pts | Headline states specific, measurable outcome user desires (not method/product) |
| 10 pts | Headline mentions outcome but not specific/measurable |
| 5 pts | Headline hints at outcome but mostly feature-focused |
| 0 pts | Headline only describes product/method, no outcome stated |

**Examples:**
- **0 pts:** "Digital Marketing Course" (product description)
- **5 pts:** "Become a Better Marketer" (vague outcome)
- **10 pts:** "Get More Customers" (outcome but not specific)
- **15 pts:** "Get 50+ Qualified Leads Per Month" (specific, measurable outcome)

**Outcome Specificity (5 points)**

| Score | Criteria |
|-------|----------|
| 5 pts | Outcome includes numbers, metrics, or vivid description |
| 3 pts | Outcome is described but not quantified |
| 0 pts | No specific outcome mentioned |

**Language Clarity (5 points)**

| Score | Criteria |
|-------|----------|
| 5 pts | Uses customer's language (what THEY say they want), not jargon |
| 3 pts | Mix of customer language and industry terms |
| 0 pts | Heavy jargon, technical terms without explanation |

---

## Component 2: Perceived Likelihood (25 points)

**What it measures:** How credible is the claim? Will the user believe they can achieve the outcome?

### Scoring Breakdown

**Social Proof Quality (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | Testimonials include before/after numbers, timeline, full name + title |
| 7 pts | Testimonials have some specifics (numbers OR timeline) |
| 4 pts | Generic positive feedback with names |
| 0 pts | No testimonials OR fake-looking quotes |

**Example:**
- **0 pts:** "Great course!" — Anonymous
- **4 pts:** "Really helped me!" — Sarah K.
- **7 pts:** "Increased my leads by 3x" — David Chen
- **10 pts:** "Went from 2 clients/month to 12 in 6 weeks. Revenue up $18k." — David Chen, Freelance Designer

**Proof Mechanisms (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | Multiple proof types: testimonials, case studies, guarantees, certifications |
| 7 pts | 2-3 proof types present |
| 4 pts | Only one proof type (usually testimonials) |
| 0 pts | No proof elements |

**Risk Reversal (5 points)**

| Score | Criteria |
|-------|----------|
| 5 pts | Strong guarantee (money-back, results-based, conditional) |
| 3 pts | Weak guarantee ("satisfaction guaranteed") or free trial mentioned |
| 0 pts | No risk reversal mechanism |

---

## Component 3: Time Delay (20 points)

**What it measures:** How fast can the user get results? (Lower time = higher value)

### Scoring Breakdown

**Timeline Specificity (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | Specific timeline stated in hero ("90 days", "first week", "in 30 minutes") |
| 7 pts | General timeframe mentioned ("fast", "soon", "quickly") |
| 0 pts | No timeline mentioned at all |

**Speed Perception (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | Timeline feels fast for the outcome (builds urgency) |
| 7 pts | Timeline feels reasonable but not exciting |
| 4 pts | Timeline feels slow (reduces urgency) |
| 0 pts | No timeline to evaluate |

**Examples:**
- **Slow (4 pts):** "Get clients in 2 years" (for a lead gen course)
- **Reasonable (7 pts):** "See results in 6 months"
- **Fast (10 pts):** "Get your first 3 clients in 30 days"

---

## Component 4: Effort & Sacrifice (30 points)

**What it measures:** How easy is it? What barriers are removed? (Lower effort = higher value)

### Scoring Breakdown

**Barrier Identification (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | Hero/subheadline explicitly names and removes 2+ common barriers |
| 7 pts | At least one barrier mentioned |
| 3 pts | Barrier implied but not stated |
| 0 pts | No barriers addressed |

**Example:**
- **10 pts:** "Get 50 leads/month **without spending thousands on ads** or **learning complex funnels**"
- **7 pts:** "Simple system for getting leads"
- **0 pts:** "Complete digital marketing course"

**Friction Reduction (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | Clear path to start, minimal steps, immediate access mentioned |
| 7 pts | Some friction points addressed |
| 4 pts | Standard signup flow, no special effort reduction |
| 0 pts | High friction (long forms, complex requirements) |

**CTA Clarity (10 points)**

| Score | Criteria |
|-------|----------|
| 10 pts | CTA uses "What + Next + Why" format (action → immediate result → benefit) |
| 7 pts | CTA states action + what happens next |
| 4 pts | CTA is clear but generic ("Sign Up", "Learn More") |
| 0 pts | Vague or missing CTA |

**Examples:**
- **0 pts:** "Click Here"
- **4 pts:** "Sign Up Now"
- **7 pts:** "Get Started → Access Course Immediately"
- **10 pts:** "Get Your Free Strategy Call → See Exactly Where You're Losing Sales → Start Fixing It This Week"

## How to Use This Rubric

### During Site Design:
1. Score each component as you write copy
2. If any component scores below "Passing", revise immediately
3. Don't proceed to next section until current section passes

### During Review:
1. Score the complete site
2. Identify lowest-scoring component
3. Focus optimization effort there first (biggest leverage point)

### Quick Audit (5-Minute Version):
Score only these 4 items (25 points each):

| Item | Quick Check | Points |
|------|-------------|--------|
| Headline | Does it state specific outcome? (not method) | /25 |
| Proof | Do testimonials have before/after numbers? | /25 |
| Timeline | Is specific time mentioned in hero? | /25 |
| Barriers | Are 2+ common obstacles explicitly removed? | /25 |

If quick audit < 70/100, run full audit.

## Common Failure Patterns

### Pattern 1: Feature-Focused (Dream Outcome = 5/25)
**Symptom:** Headline describes the product, not the result
**Fix:** Ask "What does the customer GET from this?" until you reach emotional outcome

### Pattern 2: Weak Proof (Perceived Likelihood = 10/25)
**Symptom:** Testimonials are generic praise
**Fix:** Get before/after numbers, timeline, full attribution

### Pattern 3: No Timeline (Time Delay = 0/20)
**Symptom:** Words like "eventually", "over time", or nothing at all
**Fix:** State specific, realistic timeline in hero

### Pattern 4: Barrier Blind (Effort = 12/30)
**Symptom:** Lists what's included, doesn't address why they haven't done it yet
**Fix:** Identify 3 barriers, explicitly remove each one

## Conversion Impact by Score Range

| Score | Expected Impact | Action |
|-------|----------------|--------|
| 85-100 | High conversion (5-15%+) | Ship it, split-test variants |
| 70-84 | Acceptable conversion (2-5%) | Ship and monitor, optimize after launch |
| 50-69 | Low conversion (<2%) | Revise before launch |
| <50 | Very low conversion | Complete rewrite using framework |

**Note:** These ranges assume qualified traffic. Bad targeting can't be fixed with good copy.

## Audit Checklist

Use this before finalizing any sales/lead-gen site:

**Dream Outcome**
- [ ] Headline states END RESULT, not method
- [ ] Outcome is specific and measurable
- [ ] Uses customer's language (not jargon)

**Perceived Likelihood**
- [ ] At least 3 testimonials with numbers
- [ ] Before/after states clearly shown
- [ ] Guarantee or risk reversal present
- [ ] Multiple proof types (not just testimonials)

**Time Delay**
- [ ] Specific timeline in hero section
- [ ] Timeline feels fast/exciting for the outcome
- [ ] Quick wins or early results mentioned

**Effort & Sacrifice**
- [ ] 2+ barriers explicitly named and removed
- [ ] Clear, simple path to get started
- [ ] CTA uses What + Next + Why format
- [ ] No unnecessary friction in signup process

**Overall**
- [ ] Total score ≥ 70/100
- [ ] No component below passing threshold
- [ ] Reading level = 3rd grade
- [ ] "Reason why" present (if urgency/scarcity used)
