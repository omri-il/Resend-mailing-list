# Hormozi Conversion Optimization

Apply Alex Hormozi's proven conversion frameworks to website copy and structure. Based on $100M Offers methodology: make offers so good people feel stupid saying no.

## Overview

**Core Principle:** Maximize the Value Equation

```
Value = (Dream Outcome × Perceived Likelihood)
        ─────────────────────────────────────
              (Time Delay × Effort)
```

Every site element must increase dream outcome or likelihood, OR decrease time/effort.

## When to Use

**Auto-trigger when:**
- Building landing pages for courses, products, services
- Site involves selling or lead generation
- Creating hero headlines or CTAs
- Writing testimonials or social proof
- Client brief mentions price, offer, or conversion

**Skip when:**
- Internal tools, documentation sites
- No conversion goal (purely informational)
- Explicitly told "don't optimize for conversion"

## Quick Reference: 4 Critical Checks

| Check | Bad Example | Good Example |
|-------|-------------|--------------|
| **Headline** | "Digital Marketing Course" | "Get 50+ Leads/Month in 90 Days — Without Wasting Money on Ads" |
| **CTA** | "Learn More" | "Get Your Free Strategy Call → See Exactly How to Double Sales" |
| **Proof** | "Great course!" | "Sarah got 47 orders in week 1 (was getting 2/week before)" |
| **Offer Structure** | List features | Map each feature to a specific barrier it removes |

## Core Pattern: Before/After

### Before (Feature-Focused) ❌
```json
{
  "headline": "Learn Digital Marketing",
  "subheadline": "Master social media, email, and Google Ads in 8 weeks"
}
```

**Problems:** Says WHAT you learn, not WHAT YOU GET

### After (Outcome-Focused) ✅
```json
{
  "headline": "Double Your Sales in 90 Days",
  "subheadline": "Get a proven system that brings 50+ qualified leads per month — without complex funnels or expensive ads"
}
```

**Why it works:**
- Dream Outcome: "Double sales" (what they want)
- Timeline: "90 days" (reduces time delay)
- Barrier Removal: "without complex funnels or expensive ads" (reduces effort + fear)

## Implementation Workflow

**YOU MUST complete these steps IN ORDER before writing any site copy:**

### Step 1: Value Equation Discovery (REQUIRED)

Ask these questions during brainstorming. Do NOT skip to copywriting.

```markdown
**Dream Outcome Questions:**
1. What do they REALLY want? (not the product, the END RESULT)
2. What does success look like in specific, measurable terms?
3. What's the #1 thing that would make them feel successful?

**Barrier Questions:**
4. Why haven't they achieved this yet? (list 3-5 barriers)
5. What have they tried before that didn't work?
6. What scares them about trying again?

**Timeline Questions:**
7. How fast can they realistically see results?
8. What's the specific timeline? (be concrete: "90 days" not "soon")

**Effort Questions:**
9. What makes this easier than alternatives?
10. What friction can we remove from the signup/start process?
```

### Step 2: Map Features to Barriers

DO NOT list features. Instead:

**For each barrier identified:**
1. Name the barrier
2. State the solution (your feature)
3. Explain the delivery mechanism

**Example Mapping:**

| Barrier | Solution | Delivery |
|---------|----------|----------|
| "I don't know what content to post" | Done-for-you content templates | 50 pre-written posts in Week 1 |
| "I tried ads and lost money" | Risk-free guarantee | Full refund if no leads in 60 days |
| "I don't have time to learn complex tools" | Simple 3-step system | 15 min/day implementation checklist |

### Step 3: Apply Copywriting Formulas

See [copywriting-formulas.md](copywriting-formulas.md) for full library.

**Headline Formula (use this first):**
```
[Achieve DREAM OUTCOME] in [TIMELINE] without [BIGGEST BARRIER]
```

**CTA Formula (What + Next + Why):**
```
[ACTION VERB] → [What happens immediately] → [Why it matters]

Example: "Get Your Free Audit → See Exactly Where You're Losing Sales → Start Fixing It This Week"
```

### Step 4: Add Proof with Numbers

**Generic proof (weak):** ❌
> "Great results, highly recommend!"

**Specific proof (strong):** ✅
> "Went from 2 clients/month to 12 clients/month in 6 weeks. Revenue up 340%. — David Chen, Freelance Designer"

**Required elements:**
- Before state (with number)
- After state (with number)
- Timeline
- Full name + credibility marker

### Step 5: Run Value Equation Audit

Score the site against framework. See [value-equation-audit.md](value-equation-audit.md) for rubric.

**Minimum passing scores:**
- Dream Outcome: 7/10
- Perceived Likelihood: 7/10
- Time Delay: 6/10
- Effort Reduction: 6/10

If any score below threshold, revise before proceeding.

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| "Client said 'Learn X' so I wrote 'Learn X'" | Client briefs are feature-focused. Translate to outcomes. |
| "Headline looks professional" | Professional ≠ effective. Headlines = 80% of ad dollar. Optimize ruthlessly. |
| "Testimonial is positive" | Positive ≠ proof. Need before/after numbers. |
| "CTA is standard industry practice" | Standard = ignored. Use formula: What + Next + Why |
| "Too simple to need Value Equation" | Simple sites need HIGHEST conversion — no second chances |
| "This feels too salesy" | Hormozi: "If it doesn't feel a little uncomfortable, you're not making a strong enough offer" |

## Red Flags — STOP and Audit

If you catch yourself thinking ANY of these, STOP and run Value Equation Discovery:

- ✋ "I'll just use the client's provided copy"
- ✋ "Headline is clear enough"
- ✋ "Testimonials look good"
- ✋ "CTA is obvious, doesn't need explanation"
- ✋ "This is what the template shows"
- ✋ "Too simple/quick for full analysis"

**All of these mean: You're about to build a low-converting site.**

## Quick Win Checklist

Before finalizing ANY sales/lead-gen site, verify:

- [ ] Headline states dream outcome (not method)
- [ ] Timeline is specific ("90 days" not "fast")
- [ ] At least one barrier explicitly removed in hero
- [ ] CTA uses What + Next + Why format
- [ ] Testimonials include before/after numbers
- [ ] Features mapped to barriers (not just listed)
- [ ] Guarantee or risk reversal present
- [ ] Reading level is 3rd grade (simple, clear)
- [ ] No jargon without explanation
- [ ] "Reason why" for urgency/scarcity (if any)
